# snugdoku-site

**Redirect shell.** Since 2026-10-28 Snugdoku's privacy policy, terms of use and support page (English and Turkish)
live on the developer's site:

- https://beydadonmezz.github.io/snugdoku/privacy/ · /terms/ · /support/
- https://beydadonmezz.github.io/snugdoku/tr/privacy/ · /tr/terms/ · /tr/support/

Every page here (and `404.html`, for any other old path) only redirects to its new counterpart, so links in older app
builds and store listings keep working. The pages are generated by `legal/redirects.py snugdoku-site <this checkout>`
in the app repo (beydadonmezz/snugdoku). Keep this repo and its GitHub Pages site; never delete it.
